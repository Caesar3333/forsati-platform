## Overview | نظرة عامة

Forsati is a smart digital platform connecting job seekers with opportunities using AI-powered analysis.

منصة فرصتي هي منصة رقمية ذكية تربط الباحثين عن فرص مع أصحاب الفرص باستخدام الذكاء الاصطناعي.

## Quick Start | البدء السريع

`ash
git clone https://github.com/Caesar3333/forsati-platform.git
cd forsati-platform
git submodule update --init --recursive
cp .env.example .env
docker-compose up -d
`
